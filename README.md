# hikarii — English Corner

Ứng dụng luyện tiếng Anh cá nhân, Node.js + Express + JavaScript thuần.

```bash
npm install
npm start
```

Mở http://localhost:3000. Yêu cầu Node.js >= 20. Windows có thể dùng `start.bat`.

Đọc **HUONG_DAN_BAN_MOI.md** để xem cách học, thêm nhạc YouTube, avatar, cấu hình Gemini và sao lưu dữ liệu.

```bash
npm test
```
